# MyCabinet — личный кабинет

Учебный проект по заданию от 15.09.2026.

## Страницы
- `index.html` — личный кабинет и профиль.
- `messages.html` — отправка и получение сообщений.
- `statistics.html` — статистика отправленных и полученных сообщений.
- `css/style.css` — единый CSS.

## Авторы
Евгения

## Технологии
HTML5 + CSS3. Дизайн намеренно сделан простым, без сложных библиотек, чтобы в дальнейшем было удобно переносить интерфейс в Yii2.

## Запуск
Открыть `index.html` в браузере.
